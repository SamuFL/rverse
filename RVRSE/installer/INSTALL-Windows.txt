RVRSE - Installation Guide (Windows)
------------------------------------

Thank you for downloading RVRSE!

Recommended: run the signed RVRSE Windows Setup executable. It installs:

  VST3:  C:\Program Files\Common Files\VST3\RVRSE.vst3\
  CLAP:  C:\Program Files\Common Files\CLAP\RVRSE.clap
  App:   C:\Program Files\RVRSE\RVRSE.exe

The portable zip contains the same signed binaries for manual installation.
Administrator access is required to copy them to the system plugin folders.

Then relaunch your DAW and scan for new plugins.

Windows may show a reputation warning for a newly issued signing identity even
when the signature is valid. Check that Windows reports a valid signature and
the expected verified legal publisher before continuing.
